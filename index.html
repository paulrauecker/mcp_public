Paul's MCP Hub

A personal, self-hosted tool that lets the owner's own AI agents read and manage the owner's own Google Workspace data (Gmail, Drive, Calendar, Docs, Sheets) through the Model Context Protocol. It runs on a private server, listens only on localhost, and is not offered to the public.
