Privacy Policy

Last updated: 2026-10-09

This application is a personal tool operated by Paul Rauecker ("I") for my own use. It is not a public service.

Data accessed

When I authorise the app with my Google account, it can access the Google data covered by the scopes I approve (such as Gmail, Drive, Calendar, Docs and Sheets) so that my own AI agents can act on it at my request.

How data is used

Data is used only to perform the actions I request. It is processed on a server I control. It is not sold, shared with third parties, used for advertising, or used to train generalised AI models. Content that an agent reads may be sent to the AI model provider I am chatting with, solely to answer my request.

Storage

The only thing persisted is the OAuth refresh token, stored on my private server with root-only file permissions. Google data is not copied into any database or shared location.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked any time at myaccount.google.com/permissions. Deleting the stored token removes all access.
